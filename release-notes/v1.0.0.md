## Keyscene 1.0.0 — 첫 정식 버전

단축키 하나로 Windows 동작 여러 개를 실행하고, 같은 키를 다시 누르면 원래대로 돌아갑니다.

### 새 기능

- **창 세트 전환**: 지금 열린 앱과 브라우저 창을 세트로 기록해 두고, 누를 때마다 다음 세트의 창을 띄우고 다른 세트의 앱은 최소화합니다. 세트가 하나면 다시 누를 때 원래대로 돌아갑니다. 최소화되는 앱의 소리를 끄거나 재생 중인 미디어를 일시 정지할 수 있습니다.
- **실행 조건**: 앱 열기와 창 세트 전환에서 '항상(꺼져 있으면 열기)'과 '앱이 실행 중일 때만'을 고릅니다.
- 연달아 있는 앱 열기는 동시에 열어 더 빨리 끝납니다.
- 단축키 보내기에서 숫자 패드와 음량·미디어 키도 보낼 수 있습니다.

### 달라진 점

- 원래대로 할 때 창을 원래 있던 모니터·크기·쌓인 순서로 되돌리고, 쓰던 창을 다시 활성화합니다.
- 창을 옮기거나 내릴 때 번쩍이던 것을 줄였습니다.
- 바탕 화면 보기가 관리자 권한 창을 내리지 못하면 알려 줍니다.
- 앱 열기의 기본값이 '주 모니터 · 최대화 · 원래대로 할 때 최소화'로 바뀌었습니다.
- 글자 입력의 줄 바꿈은 Enter 키로, 탭은 Tab 키로 입력합니다.

### 고친 문제

- 단축키를 녹음하다가 다른 앱으로 넘어가면 '단축키를 쓰지 않을 앱'에서도 단축키가 동작하거나, 돌아올 때까지 모든 단축키가 꺼져 있던 문제
- 앱을 바꾸는 순간에 일시 중지를 누르면 드물게 단축키 하나가 듣지 않던 문제

**설치:** `Keyscene_1.0.0_x64-setup.exe`를 받아 실행하세요(Windows 11, 64비트). 이전 버전 위에 그대로 설치하면 설정이 유지됩니다. 코드 서명이 없어 뜨는 경고는 [README의 설치](https://github.com/Jong6e/keyscene#설치)를 보세요.
