## Keyscene 0.3.0 — 첫 공개 버전 (미리 보기)

단축키 하나로 Windows 동작 여러 개를 실행하고, 같은 키를 다시 누르면 원래대로 돌아갑니다.

- 동작 26가지: 숨긴 항목·바탕 화면 아이콘·마이크·스피커·어둡게/밝게 모드 전환, 앱·파일·웹사이트 열기, 창 정리, 파일 숨기기, PC 잠금, 단축키 보내기 등
- 단축키마다 유지 시간(5분~1시간이 지나면 저절로 원래대로)
- 마이크가 음소거되면 트레이 아이콘에 빨간 배지
- 인터넷에 접속하지 않습니다("새 버전 확인"을 누를 때만 GitHub에 접속)

**설치:** 아래 `Keyscene_0.3.0_x64-setup.exe`를 받아 실행하세요. Windows 11(64비트)용입니다.
코드 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜹니다. **추가 정보 → 실행**을 누르세요. Microsoft Defender가 격리하면 README의 안내를 따라 복원하세요. 자세한 내용은 [README의 설치](https://github.com/Jong6e/keyscene#설치)를 보세요.

---

Keyscene runs several Windows actions with one keyboard shortcut and undoes them when you press it again. Windows 11, Korean UI.
